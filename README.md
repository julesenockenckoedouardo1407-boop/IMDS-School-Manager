# IMDS School Manager v4.1 — stable

Version de stabilisation de l’application de gestion scolaire IMDS.

- Fonctionnement hors connexion (PWA)
- Élèves, NISU, départements/communes, paiements et reçus
- Professeurs et paiements mensuels
- Dépenses
- Rapport financier mensuel : recettes - paiements professeurs - dépenses
- Sauvegarde/import JSON

Cette version corrige notamment une erreur JavaScript de la v4 qui empêchait le chargement complet de l’application.
